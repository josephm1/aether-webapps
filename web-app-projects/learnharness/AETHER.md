# Current Aether hosted edition

This is a separate AGPL-3.0 LearnHarness project for the matching Apps extension and
Android hosted adapter. Canonical editable source/resources and saved records live
in the shared WebApps/aether-learnharness folder. No Next/Node server, pairing or
additional provider login runs. Generated assets/dependencies stay private.

Teaching/probing, practice, graph and document adapters reuse the original source.
AI uses the app-specific model/thinking setting in Apps → Advanced, or Aether's
selection by default, with native private authentication. All roles use that resolved
selection. No unrelated coding prompts, extensions, Skills or MCP tools are attached.

Read pwa/HOSTED.md, PWA.md and the current learning-apps release handover for actual
build/install/smoke evidence and remaining gaps. A compiled module is not proof of
full parity. Preserve LICENSE, provenance in aether/upstream-recovery.json, third-party
notices and the matching downloadable AGPL corresponding-source archive.
