Setup log
The web interface is included in this bundle. No Linux setup, compiler or separate Node installation is needed.


Bring a book
Choose a PDF, text or Markdown file. It stays on this device. Paste its saved path into your learning chat and ask LearnHarness to use it.
32 MiB per file. Scanned PDFs may need OCR elsewhere. A book’s entire contents are not automatically put into every model request.


Keep making it yours
The bundle includes the editable source project. Open it in Mobile Codex to change the interface or add features.
After editing, ask Mobile Codex to rebuild the web project with its existing tools. On this computer use node mobile/build.mjs and python3 mobile/package.py. Keep backups of mobile/profile and mobile/books; clearing Mobile Codex’s app data removes them.
